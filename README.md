# FreelanceKampus (GUI JavaFX)
Nama: Zahra Chintya Bela | NPM: 2517052012

Jalankan: klik kanan `Launcher.java` > Run File, atau `mvn clean javafx:run`.

Alur: halaman depan -> pilih Penyedia / Pemesan -> halaman masing-masing (ada tombol Kembali).

- Tahap 1: layout VBox/GridPane, Label, TextField, Button, ListView
- Tahap 2: setOnAction (pindah halaman, tambah jasa, pesan jasa, ubah status lewat ComboBox)
- Tahap 3: Alert untuk kolom kosong/belum pilih jasa + try-catch NumberFormatException untuk harga
- OOP: Pengguna -> Penyedia, Pemesan; class Jasa, Pesanan; encapsulation
